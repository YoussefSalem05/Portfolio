# Machine Learning

## [Weld Seam Defect Detection](Weld_Seam)

A YOLOv8m computer-vision workflow for welding-defect object detection. The notebook prepares two dataset versions, explores annotation distributions, trains a separate detector on each version, and compares validation metrics and sample predictions.

- [Project README and setup](Weld_Seam/README.md)
- [Notebook source](Weld_Seam/ml-weld-seam.ipynb)
- [Original notebook on Kaggle](https://www.kaggle.com/code/youssefsalem05/ml-weld-seam)

Includes dataset attribution, training settings, execution requirements, and evaluation limitations. Dataset images and trained weights are not included.
